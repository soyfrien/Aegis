📲 Share-sheet setup

← Back to downloader

1. Put Aegis on your Home Screen

  1. Open this site in Safari (it must be Safari).
  2. Tap the Share button (square with an arrow), scroll down, tap Add to Home Screen, then Add.
  3. Open Aegis from the new icon. It runs full screen like an app.

iPhones keep the Home Screen app and Safari logged in separately, so you unlock Aegis once in each.

2. Make an “Aegis” Shortcut for the Share Sheet

iOS does not let web apps appear in the Share Sheet by themselves, so a tiny Shortcut does it. It takes whatever you share and opens Aegis with the link already filled in.

  1. Open the Shortcuts app → Shortcuts tab → tap + (top right).
  2. Tap the name at the top and choose Rename: Aegis. (Optional: Choose Icon.)
  3. Open the shortcut’s settings (the ⓘ button, or the name → Details) and turn on Show in Share Sheet.
  4. At the top of the shortcut the action Receive … input from Share Sheet appears. Tap the blue words and select only URLs and Text.
  5. Tap Add Action, search URL Encode, add it, and make sure its input is Shortcut Input.
  6. Add a Text action and type exactly this, then tap right after the = and insert the blue URL Encoded Text variable:
    …/share?url=
  7. Add an Open URLs action. Its input should be the Text from the step before.
  8. Tap Done.

Use it

  1. In Safari, Facebook, YouTube or any app: tap Share.
  2. Pick Aegis in the Share Sheet. If you don’t see it, scroll to the end of the app row → More / Edit Actions, and add Aegis to Favorites.
  3. Safari opens Aegis, asks for the passcode if needed, and starts the download. Tap Save to Files when it is ready.

Shared text like “Look at this https://… wow” also works: Aegis picks out the first web link. Add &auto=0 to the end of the address to only fill in the link and not start the download.

Optional: one-tap Shortcut with no browser

If the server admin has set an API token (AEGIS_API_TOKEN in /etc/aegis/aegis.env), the Shortcut can fetch the file by itself and save it straight to Files:

  1. Same steps 1–4 as above (name, Share Sheet, URLs and Text).
  2. Add Get Contents of URL. URL:
    …/api/fetch
  3. Tap Show More: Method = POST.
  4. Headers: add X-Aegis-Token = your token, and Content-Type = application/json.
  5. Request Body = JSON: add a Text field named url with the value Shortcut Input.
  6. Add Save File (turn Ask Where to Save on, or pick a Files folder).

The server waits for the download, so the Shortcut may run for a minute or two on long videos. The token is stored inside the Shortcut: don’t share the Shortcut with anyone. The token only allows downloads, not settings or OneDrive.
